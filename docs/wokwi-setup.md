# Wokwi Setup Guide
Hardware GPIO:
- RF Sensor: GPIO 34
- Red LED: GPIO 25
- Yellow LED: GPIO 26
- Green LED: GPIO 27
- Buzzer: GPIO 14
- Push Button: GPIO 33
- OLED SDA: GPIO 21
- OLED SCL: GPIO 22

Gateway:
- Run wokwi-gateway.exe for host.wokwi.internal:1883
- Or use broker.hivemq.com for cloud testing
